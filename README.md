## 📂 Tentang Proyek

**Terminal-Wattpad** adalah proyek web kreatif yang menggabungkan antarmuka baris perintah (*command-line interface*) bergaya terminal dengan penyimpanan data profil visual (seperti galeri foto dan biodata). Proyek ini dirancang untuk memberikan pengalaman eksplorasi data yang unik dan imersif langsung di browser.

---

## ✨ Fitur Utama

* **Antarmuka Terminal Interaktif** : Menjalankan berbagai perintah teks untuk menavigasi sistem.
* **Database Profil Visual** : Dilengkapi dengan aset gambar dan data profil (seperti galeri foto member).
* **Desain Responsif & Modern** : Tata letak bergaya *dark mode* / *cyberpunk* yang bersih dan nyaman dilihat.
